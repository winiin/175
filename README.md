# 175 · Қазақ тілі

Қазақ тілін үйренуге арналған шағын интерактивті білім платформасы.

## Мүмкіндіктер
- Қазақ тіліндегі адаптивті интерфейс
- 6 қысқаша теориялық сабақ
- 10 сұрақтан тұратын интерактивті тест
- Қате жауаптан кейін дұрыс жауап пен түсіндірме
- Іздеу мүмкіндігі бар шағын сөздік
- Телефон мен компьютерге бейімделген дизайн

## Іске қосу
Жобаны ашу үшін `index.html` файлын браузерде ашу жеткілікті. Қосымша сервер немесе кітапхана қажет емес.

## GitHub Pages
Репозиторийдің **Settings → Pages** бөліміне өтіп:
1. **Deploy from a branch** таңдаңыз.
2. Branch ретінде **main**, папка ретінде **/(root)** таңдаңыз.
3. **Save** батырмасын басыңыз.

Жарияланғаннан кейін сайт әдетте мына мекенжайда қолжетімді болады:
https://winiin.github.io/175/
